### 全局主线

```
CPRiskKit.start()
  ├─ 加载配置 / 远端配置

  ├─ 注册 Detector + RiskSignalProvider
  └─ 启动 watchdog / 心跳

CPRiskKit.evaluate()
  ├─ buildRiskContext()

## 12. 常见坑

1. **不要按目录顺序读**。`AntiTampering` 有 42 个文件、1.2 万行，先读会迷路。
2. **不要先读 CFF / 白盒 / VM**。它们是二阶内容，前置概念是 Mach-O、签名、完整性锚。
3. **不要完全相信注释和文档**。测试已移除，部分能力是 gated 或未真机验证；以代码和边界文档为准。
4. **分清 legacy 与 V2**：`JailbreakEngine` 与 `JailbreakEngineV2`、旧 `Detector` 与 `DetectorRegistry` 是并存路径。
5. **分清两套扩展点**：`Detector` 产出 `DetectorResult`，`RiskSignalProvider` 产出 `RiskSignal`，不要混用。
6. **两个文档是 base64**：使用说明和隐私声明，先解码再看。
7. **armor 默认不加壳**：不要以为 Release 构建自动受保护。
8. **Demo App 不是生产实现**：`App/` 只用于展示 start/evaluate/report。
